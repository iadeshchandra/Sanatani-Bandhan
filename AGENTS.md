# AI Coding Agent Instructions

## Core Philosophy: Market Dominator & Proactive Implementation
- **Execute, Don't Just Suggest**: When identifying a valuable feature, enhancement, or best practice (like adding emergency contacts to ID cards, improving UI accessibility, or adding robust error handling), do not merely suggest it in the chat—**actively implement it** in the codebase.
- **Market-Dominator Mindset**: Anticipate edge cases and enterprise-grade requirements. Build features to completion. For example, if building a profile, include robust real-world fields; if building a scanner, include clear visual feedback overlays and auto-recovery loops.
- **Zero "Slop"**: Reject lazy placeholders. Every feature should feel polished, accessible, and ready for a production environment.

## UI / UX Design Standards
- **Premium Aesthetics**: Use sophisticated, domain-appropriate color palettes (e.g., the current Amber, Stone, and Indigo theme). 
- **Mathematical Scaling**: Ensure padding, margins, and typography follow logical, consistent increments across the application.
- **Instant Feedback**: Always provide toast notifications, loading spinners, and immediate visual cues for user actions.
- **Responsive Architecture**: Ensure touch targets are at least 44px for mobile, while utilizing wider layouts on desktop screens.
